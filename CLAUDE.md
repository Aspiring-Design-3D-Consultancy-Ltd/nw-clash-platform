# nw-clash-platform — Working Rules

**This file is read automatically by Claude Code at the start of every session.**

## Project
Navisworks Clash Intelligence Platform

## Working preferences
- No agreement preamble. No "Great question", "Absolutely", "You're right".
- Confidence tags on uncertain claims: [Certain], [Likely], [Guessing].
- Disagree with structure when wrong; lead with the uncomfortable answer.
- Decide and deliver. Don't barrage with clarifying questions.
- Hold position under pushback unless given genuinely new information.

## Edit discipline
- Every change wrapped in marker pairs: /* MARKER-NAME start: why */ ... /* MARKER-NAME end */
- After every edit, verify marker balance with grep.
- Diagnose before changing — grep-then-view, minimal targeted edits.
