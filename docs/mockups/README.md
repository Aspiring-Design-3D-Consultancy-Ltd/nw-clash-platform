# UI mockups

Standalone, self-contained HTML illustrations of proposed features. They share
no code with `working.html`, read no `nw:*` keys, touch no IndexedDB, and need
no build step — open the file directly in Chrome or Edge.

| File | Scope | Status |
|------|-------|--------|
| `training-mode-mockup.html` | PR-3 Training Mode: Settings toggle, sandbox register with three practice tests and one planted near-duplicate pair, practice flow (import → register → Dedup Queue → Review Queue), persistent training banner, exit restores normal state. | Mockup only — nothing in `working.html` changed. |

The grey **Mockup guide** strip at the top of each file steps through the flow.
A **Scope notes** button lists the design decisions made in the mockup for
spot-check, and the open questions for the build.
